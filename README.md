# D3.js Examples

A collection of interactive data-visualization examples built with D3.js.

## Repository structure

```text
D3BarChart/
├── README.md
├── bar-chart/
├── scatter-plot/
├── heat-map/
├── tree-map/
└── choropleth-map/
```

## Examples

| Folder | Visualization |
| --- | --- |
| `bar-chart` | D3 bar chart |
| `scatter-plot` | D3 scatter plot |
| `heat-map` | D3 heat map |
| `tree-map` | D3 tree map |
| `choropleth-map` | D3 choropleth map |

Each folder preserves the work from one original repository. Open the HTML entry point in a browser or use a local static web server, depending on the example's requirements.
